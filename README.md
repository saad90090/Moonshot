# Moonshot

A SwiftUI information app exploring NASA's Apollo missions and the astronauts who traveled to the Moon. The app presents mission details and astronaut biographies in an organized, easy-to-navigate interface.

## Features

- Browse Apollo missions and their details.
- Explore astronaut biographies and mission assignments.
- Navigate between screens using SwiftUI navigation.
- Load and decode structured JSON data.
- Display mission information with images and formatted dates.

## Technologies Used

- **Language:** Swift
- **Framework:** SwiftUI
- **IDE:** Xcode
- **Data Handling:** JSON decoding with `Codable`
- **Navigation:** `NavigationStack` and `NavigationLink`

## Key Learnings

- Decoding JSON data into Swift models.
- Working with relationships between missions and astronauts.
- Building reusable views with SwiftUI.
- Implementing navigation between list and detail screens.
- Displaying dynamic content from local data files.

## Getting Started

1. Clone or download this repository.
2. Open `Moonshot.xcodeproj` in Xcode.
3. Select an available iOS simulator.
4. Build and run the app.

## Purpose

This project was built to strengthen my understanding of SwiftUI, JSON data handling, and navigation while creating an interactive experience around the Apollo space missions.
